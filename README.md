# PUS DOC - 브리핑일지 양식/서명 자동입력 추가본

## 이번 추가 기능
- `templates/briefing-template.xlsx` 기본 브리핑일지 양식 포함
- 관리자 모드 > 브리핑일지 항목에서 `브리핑 양식 등록/교체` 가능
- 브리핑일지 작성 시 `브리핑 적용 날짜` 선택 가능
- 직원이 브리핑 확인 시 본인 등록 서명과 확인 기록 저장
- 관리자 모드에서 선택한 년/월 기준 `월별 서명본 엑셀 다운로드`
- 다운로드 시 해당 날짜 시트에서 직원 이름을 찾아 오른쪽 Signature 칸에 서명 이미지 자동 삽입

## 업로드 방법
ZIP 압축을 풀고 내부 파일/폴더 전체를 기존 Vercel/GitHub 프로젝트에 덮어씌우세요.

필수 포함:
- index.html
- css/
- js/
- templates/briefing-template.xlsx
- firebase-messaging-sw.js

## 테스트 순서
1. 직원 계정으로 로그인 후 서명 등록
2. 관리자 모드에서 브리핑일지 작성, 적용 날짜 선택
3. 직원 계정으로 해당 브리핑 확인
4. 관리자 모드에서 해당 월 선택 후 월별 서명본 엑셀 다운로드
5. 다운로드된 엑셀에서 해당 날짜 시트의 이름 옆 Signature 칸 확인
