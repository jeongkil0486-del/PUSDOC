# PUS DOC 분리본 - 브리핑일지 엑셀 시트/서명 확인 기능

## 이번 추가 기능
- 관리자 모드 > 브리핑일지 항목에서 `일별 시트 브리핑 엑셀 업로드`
- 선택된 년/월 기준으로 엑셀 각 시트를 일자별 브리핑일지로 자동 등록
- 직원 모드 > 브리핑일지 클릭 시 근무 스케줄처럼 달력 표시
- 미확인 브리핑은 `확인 필요`, 확인 완료 브리핑은 `확인 완료` 표시
- 날짜 클릭 시 해당 일자의 브리핑일지 팝업 표시
- 직원이 내용을 끝까지 읽어야 확인 버튼 활성화
- 확인 시 직원 계정에 등록된 서명이 자동 저장
- 관리자 월별 서명본 엑셀 다운로드 유지

## 업로드 방법
압축을 푼 뒤 아래 파일/폴더 전체를 기존 프로젝트에 덮어쓰기 업로드하세요.

- index.html
- css/
- js/
- templates/
- firebase-messaging-sw.js

## 테스트 순서
1. Vercel Preview 배포
2. 관리자 로그인
3. 관리자 상단 `대상 년월 선택`
4. 브리핑일지 항목에서 엑셀 업로드
5. 직원 로그인
6. 서명 등록
7. 브리핑일지 메뉴 클릭
8. 달력에서 `확인 필요` 날짜 클릭
9. 브리핑 팝업에서 내용 확인 후 확인 버튼 활성화 확인
10. 확인 후 달력에 `확인 완료` 표시 확인
11. 관리자 월별 서명본 엑셀 다운로드 확인
