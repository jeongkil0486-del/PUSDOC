# PUS DOC 분리본 + 브리핑일지 서명 기능

## 추가된 기능
- 직원 로그인 후 상단 `서명` 버튼으로 본인 서명 등록
- 기본 항목 `브리핑일지` 자동 생성
- 관리자가 브리핑일지 작성 가능
- 직원이 브리핑일지 확인 시 등록된 서명으로 확인 기록 저장
- 관리자 화면에서 선택 년/월 기준 브리핑 확인명단 엑셀 다운로드 가능

## 업로드 시 주의
아래 전체 구조를 그대로 업로드해야 합니다.
- index.html
- firebase-messaging-sw.js
- css/style.css
- js/ 전체 파일

`firebase-messaging-sw.js`는 반드시 루트 위치에 있어야 푸시 알림 백그라운드 수신이 유지됩니다.
